## Important Rules
- 추가입고는 상태값이 아니다.
- 1차 입고는 일반 입고로 본다.
- 2차 이상 회차는 추가입고 이력으로 본다.
- inbound_status는 입고대기 / 부분입고 / 입고완료만 사용한다.
- SKU는 현재 저장하지 않고, 재고관리 앱 단계에서 본격 사용한다.
- 현재 상품 마스터는 모델명 중복 방지와 모델명 자동 생성 기준 데이터 역할이다.

## Excel
- 샘플리스트, 발주서, 입고확인서는 이미지 포함 xlsm 다운로드를 사용한다.
- 사용자는 Excel에서 “콘텐츠 사용”을 눌러야 이미지가 표시된다.
- 기존 이미지 없는 엑셀 다운로드는 일부 화면에서 비활성화했다.

## Print
- 발주관리 프린트는 표 영역, 대표 이미지, 그 외 컬러 이미지, 비고/요청사항 영역을 분리한다.
- 대표 이미지는 별도 페이지에 단독 출력한다.
- 그 외 컬러 이미지는 별도 페이지에 5열 기준으로 출력한다.
- 입고관리 프린트는 현재 정상 레이아웃 기준으로 유지한다.
