# Sample Management System

## Stack

* Next.js App Router
* TypeScript
* Supabase
* Tailwind
* shadcn/ui

## Main Modules

* 샘플관리
* 아이템카드
* 발주관리
* 입고관리
* 대시보드

## Features

* 이미지 포함 엑셀(.xlsm)
* 프린트 양식
* 입고 회차 관리
* 대시보드 상태 통계
* 모바일 대응 UI

## Important

* Excel 이미지 출력은 xlsm 매크로 사용
* 사용자는 "콘텐츠 사용" 버튼 필요
* 추가입고는 상태값이 아님
